# 3.2.0 · MONITOR LINK

可覆盖安装3.1.0/0.3.0，沿用固定测试签名。保留原NCNN Nano/Small与本地识别、定位和巡检照片。

- 原地图占位入口启用为网页仪表盘，使用系统浏览器打开固定HTTPS监控中心，配对后携带设备ID定位对应设备；本机实时统计保留。
- 工具 → 监控中心连接：输入网页设置生成的6位一次性配对码，可填写设备名。仅App前台、连接启用时每约10秒发送心跳；可暂停/解除连接，无后台定位服务。无GPS也可在线，过期/模拟位置不作为有效心跳坐标。
- 照片详情增加一键上传与重试，同事件UUID幂等；显示服务器事件编号、接收时间和上次错误。原始JPEG/JSON不改写，回执另存。3.1已有巡检记录也能上传；更旧的普通截图没有结构化JSON，继续提供查看/分享。
- 上传前校验原图SHA256，限制4MiB图片/6MiB请求。照片/位置进入公开课程Demo，可公开查看且可能被网页清空；按钮旁有提示。保留COCO类别，不将通用识别当病害。
- 令牌只在私有设置中，未写入URL/图片/JSON/日志；HTTPS默认证书校验，不跟随API重定向，私有设置/记录不随应用备份或设备转移复制。

## 测试方式

打开[监控中心](https://lvshanyewu.site/wandervision/) → 右上设置/手机连接生成配对码。手机工具/监控中心连接完成配对；留在App取景页面，看网页设备是否在线，再手动上传一张巡检照片。网页“采集档案”查看照片与原始JSON；重复上传应只有一条记录。打开浏览器后App心跳暂停，返回恢复。

开发机已做构建/lint、签名/ARM64检查、18项假传输契约测试，以及模拟器真实界面到公网的配对→心跳→拍照→上传→重复→原图/JSON核对。公网测试记录明确标TEST，没有真机GNSS或道路识别成功结论。请用小米13反馈真实网络、位置质量、照片方向与持续稳定性。
