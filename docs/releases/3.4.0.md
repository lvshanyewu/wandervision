# wandervision 3.4.0 · 实验模型与巡检规则

- 保留原四个模型，新增道路 Nano、标志36类、标志21类、车牌定位、垃圾6类、遗留物9类，共十个可选检测器，一次只运行一个。
- 车牌模式拍照时追加中文牌号 OCR，候选和置信度写入巡检照片与原始 JSON；侧斜、双层牌和夜间效果仍待实测。
- 新增“实验”面板：固定机位 ROI 停留、反向轨迹、虚拟线跨越、已知类别道路异物提示。移动手机前关闭；这些提示不等于违法判定。
- 可选1280×720采集档，失败/无首帧自动回到640×480；实验室可一键恢复原 COCO Nano 基线。位置、照片、配对、LIVE继续保留。

测试重点：先 CPU/320 逐个切换模型，测试标志、瓶/杯/纸盒、车牌框及拍照后的号码候选；再比较480/640与系统Vulkan。固定手机后测试ROI规则。记录漏检/错类、照片内容、切换黑屏或崩溃情况，便于下一版删减候选。

55项模拟器契约/原生检查、六模型18种形状的转换核验及OCR数值对照通过；不代表小米13的准确率、FPS、摄像头和定位已经验证。水坑模型因无明确再分发许可未打包；设施损坏、事故、特种车型、真实超速/超高/车距未实现。Turnip未集成，沿用系统Vulkan。固定机位虚拟线不代表自动识别实线或应急车道。

沿用既有测试签名，可覆盖安装；所有模型随包提供，APK体积相应增加。模型与范围说明见仓库 `docs/teacher-scope-feasibility.md`。
