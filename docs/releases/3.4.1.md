# wandervision 3.4.1 · 课设数据采集

- App副标题调整为“道路巡检具身智能体”。
- 设置新增“采集点与备注”，仅用于后续新照片：采集点最多80个Unicode字符，备注最多240个。拍照时固定写入原JSON，照片显示缩略文本，详情可查看完整说明。
- 上传按钮说明照片与完整结构化条目一起上传，包含采集时间、设备、位置与精度/无定位、模型与每目标结果、已有OCR与实验规则。保留schema1.0、原JPEG校验、event_id幂等及独立回执，兼容旧记录。
- 十个模型与检测链路沿用3.4.0，本轮不增加模型、不修改Web/API。

测试重点：设置采集点和备注后拍照，在详情/导出JSON检查说明与检测字段；上传到已配对课程数据汇集中心，确认统一台账收到条目，同一记录重试不重复。旧照片继续可查看、分享与上传。真机相机/GNSS/推理效果继续以用户反馈为准。
