# 0.2.0 · FIELD INSTRUMENT

专业手持识别仪风格的相机测试版。暗色取景器、液晶状态面板、金属渐变参数键与立体快门，替换旧版 Spinner 和系统按钮。

- 保留原 YOLOv8 **Nano**，新增同源 **Small** COCO 80 类模型；Small 容量更大，效果与速度请在真机对比，不保证夜间一定更好。
- 通用、车辆、纯取景三种模式；Nano/Small × 320/480/640 × CPU/Vulkan 可切换并记住选择。
- 真实 FPS、推理耗时、当前帧目标数；面板可打开本地统计快照与近期 FPS 趋势。目标数不代表去重车辆总数。
- 快门保存当前屏幕（取景画面、检测框和信息）到系统相册 `Pictures/wandervision`。提供最近 30 张记录、查看和系统分享；没有录像功能。
- 构图网格、前后镜头、开源许可查看；云端同步与 GPS 明确显示未接入，没有网络或位置权限。
- 小米 13 适配目标：6.36 英寸、2400×1080、20:9（[小米官方](https://www.mi.com/global/product/xiaomi-13/specs/)）。dp 布局与系统安全区域适配；横屏将控制区放在右侧。
- 画面和框/标签统一跟随系统显示方向，移除独立重力旋转与回转；标签改为紧凑深色底，避免旧版白色标签遮挡画面。

## 安装

下载 `wandervision-0.2.0-arm64.apk`。本版开始使用固定的专用测试签名。**从 0.1.0 安装若提示签名冲突，请先卸载旧版**；卸载会清除应用数据。以后使用相同签名的 Release 可覆盖升级。

Android 7.0+ / ARM64；截图保存到相册需 Android 10+（小米 13 满足）。截图不额外申请存储权限。仍为测试版，真实检测、方向、GPU 性能和发热等待用户验收。

## 请优先测试

1. 小米 13 竖屏和左右横屏：画面、检测框与英文标签是否始终正向，切镜头及前后台恢复是否正常。
2. 先用 **Nano / 320 / CPU** 复测室内与夜间车辆；再用 **Small / 480 / CPU** 对比细节和 FPS。必要时比较 GPU 与 640；记录实际引擎显示、发热和卡顿。
3. 使用“纯取景”查看界面和相机，不绘制检测框、不执行推理；再切回通用/车辆。
4. 点击快门：确认相册能看到完整画面和框，截图记录可查看/分享；图像已被外部删除时应提示不可用。
5. 设置里开关网格、打开仪表盘；旋转手机或退回桌面再进入，确认无崩溃。

开发机通过构建、lint、模型/ABI/签名检查，并用 x86_64 模拟器检查界面与操作流程。模拟器数据不代表小米 13 的推理性能。0.1.0 已获得用户“正常启动、夜间车辆识别可用”的反馈；本版改变了 UI、模型选择与预览方向，需重新真机确认。
