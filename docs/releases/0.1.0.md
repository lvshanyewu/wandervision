# 0.1.0 — 首个 ARM64 真机测试版

本地 YOLOv8 Nano / NCNN 检测；通用物体与车辆显示模式；320/480/640 输入尺寸；CPU 与 Vulkan GPU；前后摄像头切换。仅相机权限，无网络权限，无数据上传。

**安装**：下载 `wandervision-0.1.0-arm64.apk`，在 Android ARM64 手机上安装并允许相机权限。可与原版 yolov8ncnn 并存。此 APK 使用测试签名。

**建议按顺序测试**：

1. 默认“通用物体 / Nano 320 / CPU”，对准杯子、瓶子、椅子或键盘，观察预览、框、标签和 FPS。
2. 首次拒绝相机权限，确认不崩溃；在系统设置允许后重新进入，检查预览恢复。
3. 切换前后镜头；退到后台再回来；旋转手机；检查预览和检测恢复。
4. 切换 480 / 640，再切 GPU，记录 FPS、发热、画面是否异常；GPU 不支持时会使用 CPU。
5. 在安全位置观察车辆，切换“车辆”模式；只显示自行车、汽车、摩托车、公交车和卡车。
6. 连续运行 5–10 分钟，观察卡顿、闪退、发热和耗电。

**请反馈**：手机型号 / Android 版本、模式与尺寸、CPU/GPU、FPS 大致范围、故障步骤与截图。无需驾驶中操作手机。

**验证边界**：电脑可验证 Java/C++ 构建、Android lint、APK 签名与 ARM64 ELF/模型打包；没有连接 ARM64 真机，尚未确认摄像头、检测效果、性能和长期稳定性。只有通用模型，无道路病害、GPS、记录、服务器和 Web。

已知限制：UI 为简化原生界面，完整 MD3 后续实现；车辆模式是 COCO 类别过滤；检测标签沿用英文；模型切换可能短暂停顿。不同构建环境的测试签名可能不同，更新若提示签名冲突需先卸载旧版。
