# 3.1.0 · GEO CAPTURE

按本轮要求使用版本号3.1.0（versionCode4），与0.2.0/0.3.0同一固定测试签名，可覆盖安装并保留旧截图记录。

- 所有应用内面板统一从底部上滑进入、向下退出，横屏同样由底部进入。系统权限/分享/文件选择器保留系统表现。
- 黄色快门改为生成独立巡检照片：带识别框的取景画面 + 时间、WGS84位置/精度/样本年龄、模式/模型/输入/实际计算引擎、识别统计与记录编号，不截取按钮或状态栏。
- JNI按需抓取下一处理帧，照片、目标类别/置信度/归一化框、统计来自同一帧；纯取景明确不执行识别。来源仍是预览帧，不是高分辨率静态拍照。
- 新增前台定位，GPS/系统network约10秒请求一次；底部显示经纬度和精度。只授权近似位置、拒绝权限、关闭系统定位、信号不足均可继续识别/取景；过期位置明确标注。离开应用停止请求，无后台定位或Google服务依赖。
- 每张照片持久化JSON，包含UUID、安装来源ID、帧信息、检测结果、定位质量与时间、图片SHA256和local_only状态。记录详情支持照片+JSON分享、单独导出JSON。新鲜/近似位置写入GPS EXIF；分享照片会附带位置。
- 保留现有COCO Nano/Small和CPU/系统Vulkan，不增加病害模型或Turnip开关。已完成预训练路面模型和Turnip源码/二进制兼容调查，详见仓库 `docs/road-models-and-turnip.md`；当前没有连接或上传到监控中心。

## 小米13测试重点

1. 覆盖安装后，允许“仅使用应用时”的定位权限；室外等待首次定位，查看底部坐标/精度是否合理。也请试拒绝/近似权限，确认仍可识别和拍照。
2. 竖屏与左右横屏分别取景，确认照片只有相机画面和信息区、识别框方向正确、文字完整，画面与记录没有串模式。
3. 记录详情查看照片和位置，尝试“导出JSON文件”或“分享照片+JSON记录”，核对接收端拿到两份文件。旧版截图仍应可查看。
4. 关闭定位或离开应用再返回，检查状态与恢复行为；按实际使用反馈定位耗电和持续稳定性。模拟器不能验证骁龙性能或真实GNSS质量。

JSON在应用私有目录，卸载/清除数据会移除；相册图片与JSON应一起导出备份。最近列表30条，JSON没有自动清理上限，本版仍为手动记录、小步测试。结构定义与检查工具见 `docs/inspection-record.md`、`tools/check_report.py`。
