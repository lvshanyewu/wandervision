# 0.3.0 · FIELD UI

本轮仅优化前端视觉，参考用户提供的黑灰黄巡检设备界面；使用原生View、Canvas与矢量图形，没有贴图外壳或重拟物装饰。

- 黑灰底、亮黄色选中态与快门、绿色帧率弧形表；新品牌标志、紧凑侧边工具栏和底部导航。
- 已有真实数据重排为帧率、**最高**置信度、当前帧目标、推理耗时四张卡片；仪表盘采用同样风格，保留真实帧率趋势。
- 相册记录改为缩略图卡片，显示实际时间、模式、模型、输入尺寸与当前帧目标数；保留查看与系统分享。
- 统一设置、模型选择、截图详情等面板；横屏参数区在右侧，竖屏在下方。
- 检测框与标签换为黄色系；模型权重、阈值、输出解析、相机方向和截图保存逻辑保持原基线，只有截图圆角随新布局调整。
- **未增加模型**，保留原Nano/Small和通用/车辆/纯取景。地图、轨迹为灰色禁用占位；没有参考图中的虚构GPS、速度、温度、坑洞或同步状态。

## 安装与检查重点

下载 `wandervision-0.3.0-arm64.apk`。与0.2.0使用同一固定测试签名，可覆盖安装，保留已有配置和截图记录。

请在小米13查看：竖屏/左右横屏布局、底部安全区、字体是否清晰、侧栏与模式切换是否顺手、黄色标注是否遮挡目标。顺便复测截图相册/记录详情及模型/CPU-GPU选择；本轮重点是界面体验。

开发机执行构建、lint、ARM64模型/签名/对齐检查，并在1080×2400模拟器检查布局、面板、截图与记录。模拟器截图中的彩色块来自模拟相机，不是应用背景素材；不代表真机检测效果或性能。
