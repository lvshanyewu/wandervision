# wandervision 3.3.0 · LIVE + ROAD MODELS

- 点击取景器左上LIVE开启/关闭实时画面传输；首次开启提示公开演示用途。仅前台、配对启用时传输，进入后台或切换镜头/模型自动关闭。目标10–15FPS，按钮显示服务器确认发送帧率；网络慢时丢旧帧，不积压。
- App内置适合手机的监控概览和校园设备地图，查看设备状态和当前LIVE，不必离开相机。
- 保留COCO Nano/Small通用与车辆模式；新增RDD2022 Nano/Small路害模式：纵裂、横裂、龟裂、坑洞，可在模型菜单对照。一次只运行所选模型。
- 简化本地仪表盘、修复底部弹窗尺寸和动画位移。照片与原始JSON、手动幂等上传继续保留。

测试重点：小米13上切换四个模型和320/480/640输入、CPU/Vulkan；测试相机方向/夜间车辆与实景裂缝坑洞；网页配对后打开LIVE并在网页查看，关闭/切后台后应停止；检查App内地图与设备状态。位置未获取时应明确显示待定位。

10–15FPS为目标，不保证弱网帧率；实时帧短暂保存在服务器内存，不等同照片归档。公开Demo可被其他观看者看到，请按需开启。道路模型为预训练实验选项，电脑转换与模拟器检查不证明真实道路准确率。未集成Turnip。沿用3.2测试签名，可覆盖安装。

验证边界：34项模拟器契约/原生模型检查通过；Web长流合成输入约12FPS，App内地图已加载。最后一版原生HTTP/1.1连续上传仍需你在小米13验证，初次连接可能等待数秒；如长时间显示等待接收，请反馈，不代表已达10–15FPS。
